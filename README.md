# PDF一発

ブラウザの中だけで動く、小さいPDFツールです。ログインも広告もありません。

- 選んだ写真を、1つのPDFにします。
- すでにあるPDFを、選んだ順に1つにします。

ファイルは保存しません。結果はダウンロードするだけです。最初の読み込みのあと、オフラインで使えます。

English button labels are optional. The page stays in Japanese aside from those buttons.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Published with GitHub Pages from `.github/workflows/pages.yml`. PWA icon PNG files are not in this repo.
